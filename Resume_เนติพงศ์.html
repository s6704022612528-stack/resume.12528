สรุปข้อมูลส่วนตัว

นักศึกษาสาขาคณิตศาสตร์เชิงวิทยาการคอมพิวเตอร์ มหาวิทยาลัยเทคโนโลยีพระจอมเกล้าพระนครเหนือ มีความสนใจด้านการพัฒนาซอฟต์แวร์ การวิเคราะห์ข้อมูล และการแก้ปัญหาเชิงตรรกะ มีประสบการณ์พัฒนาระบบ POS ด้วยตนเอง สามารถนำความรู้ด้านคณิตศาสตร์และการเขียนโปรแกรมมาประยุกต์ใช้กับงานจริง ขยันเรียนรู้เทคโนโลยีใหม่ ๆ และพร้อมทำงานร่วมกับทีม

การศึกษา

วิทยาศาสตรบัณฑิต สาขาคณิตศาสตร์เชิงวิทยาการคอมพิวเตอร์พ.ศ. 2567 - ปัจจุบัน

มหาวิทยาลัยเทคโนโลยีพระจอมเกล้าพระนครเหนือ (มจพ.)

  • วิชาที่เกี่ยวข้อง: โครงสร้างข้อมูลและอัลกอริทึม, ฐานข้อมูล, พีชคณิตเชิงเส้น, สถิติและความน่าจะเป็น

โปรเจกต์

ระบบ POS (Point of Sale)โปรเจกต์ส่วนตัว
  • พัฒนาระบบขายหน้าร้านสำหรับบันทึกรายการขายและคำนวณยอดชำระเงิน
  • จัดการข้อมูลสินค้าและสต็อก พร้อมออกใบเสร็จรับเงิน
  • สรุปรายงานยอดขายรายวันและรายเดือนเพื่อช่วยในการตัดสินใจของร้านค้า
ระบบวิเคราะห์และพยากรณ์ยอดขายโปรเจกต์ในรายวิชา
  • ใช้ Python และเทคนิคทางสถิติวิเคราะห์แนวโน้มข้อมูลยอดขายย้อนหลัง
  • สร้างโมเดลพยากรณ์อย่างง่ายและแสดงผลเป็นกราฟเพื่อให้เข้าใจง่าย
เว็บแอปพลิเคชันจัดการงานและตารางเวลาโปรเจกต์กลุ่ม
  • ออกแบบฐานข้อมูลและพัฒนาฟังก์ชันเพิ่ม แก้ไข และติดตามสถานะงาน
  • ทำงานเป็นทีมโดยแบ่งหน้าที่ ใช้ Git ในการจัดการเวอร์ชันของโค้ด

ข้อมูลเพิ่มเติม

  • ทักษะทางเทคนิค: Python, Java, SQL, HTML/CSS, JavaScript, Git
  • ทักษะอื่น ๆ: การวิเคราะห์ข้อมูล, การแก้ปัญหาเชิงตรรกะ, การทำงานเป็นทีม, การเรียนรู้ด้วยตนเอง
  • ภาษา: ไทย, อังกฤษ
